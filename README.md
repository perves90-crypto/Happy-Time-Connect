# Happy Time Connect

Company messaging and collaboration app for T.K Food Products Distribution Limited.

## Planned capabilities
- Phone-number sign-up with OTP verification and persistent sessions
- Personal and group messaging
- Secret-code protected private conversations
- Personal cloud storage and automatic phone downloads
- Audio and video calls, targeting at least 100 participants per group call
- Mobile-first, performance-conscious interface

## Current status
Version 0.1 is the initial responsive UI scaffold only. Authentication, database, file storage, messaging, and calling are not connected yet.

## Development
```bash
npm install
npm run dev
npm run build
```

## Cost and service limits
The project is being designed around free/open-source tiers. SMS delivery, cloud storage capacity, and 100-person real-time audio/video calling depend on provider limits and cannot be promised as unlimited or always free. No paid service should be enabled without the owner's approval.
